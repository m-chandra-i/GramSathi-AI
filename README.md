# GramSathi AI 🌾

AI-powered rural assistant for farmers and rural communities.

## Features (Phase 1)
- Crop information
- Weather updates
- Government scheme suggestions
- Market price information

## Future Features
- Hindi voice assistant
- AI chatbot
- Crop disease detection
- Price prediction using ML

## Tech Stack
- Python
- Streamlit
- APIs
- Git/GitHub
