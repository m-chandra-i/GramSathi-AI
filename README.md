## 🎯 About

GramSathi AI empowers farmers and rural communities across Rajasthan with intelligent crop recommendations. Get personalized guidance based on your location, soil type, water availability, and seasonal conditions—all in a simple, user-friendly interface.

**No installation required!** [Start using it now](https://gramsathi-ai.streamlit.app/)

---

## 🚀 Quick Start

### 📱 Use the App Online (Recommended)
1. Visit **[gramsathi-ai.streamlit.app](https://gramsathi-ai.streamlit.app/)**
2. Select your village/district
3. Describe your farming situation
4. Get AI-powered crop recommendations instantly
5. Compare crops and download data for offline use

### 💻 Run Locally

```bash
# Clone the repository
git clone https://github.com/m-chandra-i/GramSathi-AI.git
cd GramSathi-AI

# Install dependencies
pip install -r requirements.txt

# Launch the app
streamlit run app.py
```

**Requirements:** Python 3.8+

## ✨ Key Features

### 🗾 Comprehensive Database
- **50+ Rajasthan crops** with detailed information
- Hindi & English language support
- Multi-search capability (name, district, zone, season)

### 🔍 Smart Filtering
- **By Season:** Kharif, Rabi, Summer, Perennial
- **By Water Needs:** Low, Medium, High
- **By Soil Type:** Sandy, Loamy, Clay, etc.
- **By Zone:** Arid West, Shekhawati, Mewar, Hadoti, & more

### 📊 Planning & Decision Tools
| Feature | Benefit |
|---------|---------|
| **Crop Comparison** | Compare 2-3 crops side-by-side |
| **Crop Calendar** | Sowing & harvesting schedules |
| **Seed Calculator** | Calculate seed requirements |
| **Village Planner** | Zone-specific crop recommendations |
| **Data Export** | Download as CSV for offline access |

### 💡 Detailed Crop Insights
Each crop includes:
- Sowing & harvesting times
- Soil requirements & water needs
- Temperature & rainfall ranges
- Common farming issues & solutions
- Best practices for maximum yield
- Market uses & economic value
